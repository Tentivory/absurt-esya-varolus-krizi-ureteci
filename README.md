# Absürt Eşya Varoluş Krizi Üreteci

## Ne bu ya?

Bu proje, evinizdeki eşyaların iç dünyasını ortaya çıkaran devrim niteliğinde, tamamen gereksiz ama %100 çalışan bir Python scriptidir. 

Çay bardağınız neden üzgün? Kumandanız neden varlığını sorguluyor? Bu soruların cevaplarını burada bulamazsınız ama en azından absürt krizler üretebilirsiniz.

## Nasıl Çalıştırılır?

```bash
python3 esya_krizi.py
```

Gerçekten çalışır. Uyarı: Eşyalarınızla empati kurabilirsiniz, risk size ait.

## Özellikler

- Rastgele eşya + rastgele varoluşsal kriz
- Gecikmeli dramatik etki için time.sleep
- Gizli mesaj (ciddi değil, şaka olsun diye)
- Hiçbir işe yaramaz ama eğlencelidir

## Neden?

Çünkü neden olmasın? Evren zaten absürt, eşyalar da katılsın.
